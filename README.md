# 💊 Smart Pill Dispenser System

## 📖 Overview

The Smart Pill Dispenser System is a multidisciplinary healthcare project developed to improve medication adherence and reduce missed doses through a combination of hardware automation and software management.

The system consists of a physical automated pill dispensing unit integrated with a web-based platform that allows users to manage medications, track schedules, monitor inventory, and receive timely reminders. The project combines principles from Computer Science, Electrical Engineering, and Mechanical Engineering to deliver a complete smart healthcare solution.

This project was successfully designed, developed, and tested as a collaborative multidisciplinary engineering project.

---

## 🎯 Problem Statement

Medication non-adherence is a major healthcare challenge, especially among elderly individuals and patients with chronic illnesses. Forgetting medication schedules can lead to serious health complications and reduced treatment effectiveness.

Traditional pill organizers provide storage but lack automation, monitoring, and intelligent scheduling capabilities.

The Smart Pill Dispenser addresses these challenges by providing:

- Automated medication dispensing
- Medication schedule management
- Reminder and tracking features
- Inventory monitoring
- Centralized digital management

## 🚀 Installation

### Clone Repository

```bash
git clone <repository-url>
cd smart-pill-dispenser
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Configure Environment Variables

Create a `.env` file:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Start Development Server

```bash
npm run dev
```

or

```bash
npm start
```
